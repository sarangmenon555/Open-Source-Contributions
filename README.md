## My Approach to Open Source

My goal is to become a consistent and responsible open-source contributor.

I aim to understand projects before contributing, investigate issues carefully, communicate with maintainers, write maintainable code, test my changes and learn from code reviews.

I believe meaningful open-source participation is about more than the number of commits or pull requests. It is about contributing useful improvements, collaborating with developers and continuously improving engineering skills.
